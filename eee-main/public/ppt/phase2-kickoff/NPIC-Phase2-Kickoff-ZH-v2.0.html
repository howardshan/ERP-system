四大业务痛点

01 · 生产追踪

Excel 日报手工录入

每位主管每天约需 2 小时录入；易出错、无实时可见性；效率指标需手工计算；无法追踪车次生产时间。

02 · 烘房

纸质车辆记录

无法系统追踪车辆链；半车接续跨班记录混乱；与生产记录脱节，追溯困难。

03 · 资料汇总

Excel 手动汇总

无统一报表视图；提取班次汇总或效率趋势需额外人工整理；管理层决策滞后。

04 · Sage 100

生产记录双重录入

所有生产记录由员工手动逐条录入 Sage 100；转录易错；生产与系统数据存在延迟。

模块 A — 生产 · 主管批量录入

A
主管批量录入

替代现有 Excel 日报。主管可批量录入某一班次或时段内所有员工和车辆的记录。适用于没有独立条码扫描站的团队。

  • 员工姓名及工号、机器分配
  • 工单号、一级单（原材料编号）
  • 车号、层数及每车数量 / 重量
  • 班次时长与总工时
界面布局与现有 Excel 表单保持一致，降低切换成本。

自动输出

  • 各员工效率指标 → 汇入模块 D 报表
  • 记录与工单关联 → 供模块 E 同步至 Sage 100
  • 班次级产量与工时汇总

使用场景

  • 特殊班次 / 无独立扫描站产线
  • 补录或批量校正
  • 与模块 B 互补，非互斥

模块 B — 生产 · 员工站点模式

B
员工站点模式

面向员工的实时生产录入界面，部署在机器或产线旁的共享平板 / 终端。日常录入无需 MFA。

  • 工号输入或刷卡签到；同机可多人同时在线
  • 签出需电子签名；全员签完自动结束班次
  • 首车录入工单号，后续车默认上次值（须确认）
  • 一车可关联多个一级工单号
  • 必填字段按 SKU 预配置自动生效

半车接续（首车必选）

  • 独立新车 — 本班从头开始的新一车
  • 半车接续 — 与上一班某车物理接续并关联车号
  • 烘房 / 报表 / Sage 同步自动继承该关联

关单 — 受限操作（需 MFA）

  • 无剩余 — 物料用尽，干净关闭
  • 剩余物料作废 — 未用料分摊至各车核算
  • 保留剩余物料 — 留存供下次生产
关单继承 Phase 1 模块 I：Microsoft Authenticator 验证。

模块 C — 烘房操作

C
烘房操作

记录车辆进出烘房，并与生产记录自动关联。半车绑定关系已在模块 B 中建立，烘房无需重新确认。

  • 扫码入库 — 扫描车辆条码，自动提取生产信息并记录入库时间戳
  • 扫码出库 — 记录车辆离开烘房的时间戳
  • 半车绑定关系自动继承，无断链
返烘队列、时间 / 温度记录等细节将在需求确认阶段与 NPIC 共同敲定。

与 Phase 1 的衔接

  • 复用已有条码扫描基础设施
  • 可与 Phase 1 烘干房监控数据互补
  • 车辆链从生产 → 烘房全程贯通

价值

  • 消除纸质车记录
  • 跨班半车不再混乱
  • 为等待时长分析提供数据基础

模块 D — 资料总计与报表

D
资料总计与报表

将模块 A / B 录入的所有生产数据汇聚成结构化报表和导出文件，替代现有 Excel 手动汇总流程。

  • 班次汇总：总车数、产量 / 重量、工时、在线人数
  • 按日汇总：全机台、全工单当日生产情况
  • 工单完工报表：计划量 vs 实际量、物料核算状态

效率报表

  • 各员工产出指标（任意日期范围）
  • 机台利用率：有效工时 vs 停机时长
  • 趋势分析：按产品 / 工单周度 / 月度对比

数据导出

  • 按日期范围或产品 SKU 导出
  • 格式：Excel 及 PDF
  • 复用 Phase 1 导出框架，保持一致体验

模块 F — 配粉管理（新增）

F
配粉管理

取代现在在 Sage 100 中人工估算的做法：按 SKU 配方自动展开配粉用量，取粉单下发原材料库与配粉车间，全程记录两级粉料库存的转移与消耗。

  • 按 SKU 维护粉料配方（占比 + 版本与生效控制）
  • 每个一级工单录入计划重量，自动展开各粉料用量
  • 先用配粉车间现有库存，缺口才从原材料库领取
  • 原材料库缺口按 FIFO 自动指定批次，单据直出批次号

两级粉料库存的建立

  • 原材料库 — 以 Sage 100 为源建账，余额与每笔入库持续联动
  • 配粉车间 — Sage 中原本没有这级库存，由本系统首次建账；实耗按 BOM 回写 Sage

取粉单 — 双联下发

  • 原材料库版 — 仅列需出库的粉料、数量与 FIFO 批次
  • 配粉车间版 — 全量用料，两个来源分别标注

库存两次过账

  • 发料（转移） — 仓管确认「已发料」，原材料库扣减、同量转入配粉车间
  • 配粉（消耗） — 车间回填实际用量，从配粉车间库存扣减
实际少于计划 → 余量留配粉车间；超过计划 → 须另开取粉单补料，不允许直接超扣。实耗按 BOM 回写 Sage 100。

核心设计原则

01

员工模式轻量

专为车间设计，日常录入无需 MFA，支持刷卡或工号打卡。

02

主管模式对齐 Excel

批量录入界面布局与现有 Excel 表单一致。

03

按 SKU 配置字段

重量 vs 数量、层数、必填工单字段按产品自动生效。

04

半车一次绑定

生产环节绑定后，下游烘房 / 报表 / Sage 自动继承。

05

配粉两级库存

发料是转移，回填实际用量才是消耗，两笔分别过账。

06

取粉按 FIFO 出批次

缺口部分自动指定批次，单据直出批次号，仓管无需现场判断。
