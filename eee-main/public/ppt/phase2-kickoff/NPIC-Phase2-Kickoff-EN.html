Four Operational Pain Points

01 · Production Tracking

Manual Excel daily report

~2 hours/day per supervisor; error-prone; no real-time visibility; productivity metrics calculated by hand; no cart-level timing.

02 · Dry Room

Paper cart records

No system cart-chain tracking; half-cart handoffs across shifts are messy; disconnected from production records.

03 · Data Summaries

Manual Excel rollups

No unified report view; shift summaries and trends require extra manual work; management decisions lag.

04 · Sage 100

Production double-entry

Every production record re-keyed into Sage 100; transcription errors; delay between floor reality and system data.

System Bridge

Module A — Production · Supervisor Batch Entry

A
Supervisor Batch Entry

Replaces the Excel daily report. Supervisors batch-enter all employee and cart records for a shift/period. Designed for teams without a dedicated barcode station.

  • Employee name / ID and machine assignment
  • Work order and primary BOM (raw material code)
  • Cart #, layers, qty / weight per cart
  • Shift duration and total labor hours
UI layout mirrors the existing Excel form to minimize change friction.

Auto Outputs

  • Per-employee productivity → Module D reports
  • Records linked to work orders → Module E / Sage 100
  • Shift-level output and labor rollups

When to Use

  • Special shifts / lines without scan stations
  • Backfill or bulk corrections
  • Complements Module B — not mutually exclusive

Module B — Production · Employee Station Mode

B
Employee Station Mode

Real-time entry UI for employees on shared tablets / terminals at the machine. Day-to-day entry does not require MFA.

  • Sign in by employee ID or badge; multiple users per machine
  • Sign-out requires e-signature; shift ends when all signed out
  • First cart requires work order; later carts default (must confirm)
  • One cart can link to multiple primary work orders
  • Required fields auto-applied by product SKU config

Half-Cart Continuity (required on first cart)

  • New cart — starts fresh this shift
  • Half-cart continue — physical continuation of a prior-shift cart
  • Dry room / reports / Sage inherit the link automatically

Close Work Order — Restricted (MFA)

  • No remainder — clean close, material exhausted
  • Scrap remainder — unused material allocated across carts
  • Keep remainder — hold for next production run
Close WO inherits Phase 1 Module I: Microsoft Authenticator gating.

Module C — Dry Room Operations

C
Dry Room Operations

Records cart in/out of the dry room and auto-links to production. Half-cart bindings are established in Module B — no re-confirmation needed here.

  • Scan in — scan cart barcode; pull production info + timestamp
  • Scan out — record exit timestamp
  • Half-cart links inherited — no broken chain
Redry queue, time/temperature logging, etc. to be finalized with NPIC in requirements week.

Bridge to Phase 1

  • Reuses existing barcode scanning infrastructure
  • Complements Phase 1 dry-room monitoring
  • Cart chain continuous from production → dry room

Value

  • Retire paper cart logs
  • Cross-shift half-carts stay coherent
  • Foundation for wait-time analytics

Module D — Data Summary & Reporting

D
Summary & Reporting

Aggregates all Module A/B production data into structured reports and exports — replacing manual Excel rollups.

  • Shift summary: carts, qty/weight, labor hours, headcount
  • Daily rollup across machines and work orders
  • WO completion: plan vs actual, material reconciliation

Productivity Reports

  • Per-employee output for any date range
  • Machine utilization: productive vs downtime
  • Trends by product / WO — weekly & monthly

Exports

  • Filter by date range or product SKU
  • Formats: Excel and PDF
  • Reuses Phase 1 export framework for consistency

Module E — Sage 100 Bi-directional Integration

← Pull from Sage 100
Work Orders
Auto-populate WO numbers in Modules A & B
Item Master / BOM
Sync SKUs, descriptions, raw material codes
Customer POs
Link WOs to customer POs for end-to-end trace
Inventory Levels
Show real-time raw material availability when opening a WO
→ Push to Sage 100
Finished Goods Receipt
Auto-post on Module B work-order close
Raw Material Usage
Reconciled consumption posted back to inventory
Lot Numbers
Production lots synced for full-chain traceability
Cart / Output Qty
Final confirmed production quantities from A/B
